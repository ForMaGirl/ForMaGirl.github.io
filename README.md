# My Special Person

A handcrafted, responsive romantic website for , built with only HTML, CSS, and vanilla JavaScript.

## Add your song

For reliable playback, create an `audio` folder beside `index.html` and save the song as:

`audio/our-song.mp3`

Tap either the floating play button or the Music control in the header. If the local file is missing or the browser blocks it, the page opens the Spotify song instead.

## Customize

- Update the words and names in `index.html`.
- Change the relationship start date in `script.js` (`const start`).
- Update the Spotify URL and local audio filename in `index.html`.
- Tweak color tokens at the top of `style.css`.

Open `index.html` in any modern browser. No build step or dependencies are required.
